# 2.2.2 Release Notes

This release includes the changes accumulated since 2.0.0. Install with
`npm install @0disoft/openfeature-local-provider@^2 @openfeature/server-sdk`.
Publication is confirmed separately in
[registry consumer evidence](../../testing/registry-consumer-evidence.md).

## Changes

- `compare --output markdown` produces bounded, readable flag-change reports.
- `compare --output html` produces a self-contained offline visualization with no
  external resources. JSON output and exit-code precedence are preserved.
- Application lifecycle examples cover shared startup, retry, shutdown, file
  watching and audit flushing without closing other OpenFeature domains.
- Audit evidence export cancellation now interrupts process-queue admission and
  lock retry waits. Cancelled pending operations detach in O(1), preserve their
  original cancellation reason and cannot later create export destinations.
- Read-only PR review guidance includes a synthetic comparison corpus.
- Node.js 26 qualification tooling and local Windows/Linux results are recorded;
  macOS qualification remains deferred. Supported Node versions remain 22 and 24.

## Compatibility And Recovery

Public provider signatures, snapshot and audit formats, deterministic evaluation,
override priority and dependency ranges are unchanged from 2.0.0. The CLI output
formats are additive. No configuration or stored-data migration is required.

Cancellation cannot preempt an already-started filesystem operation. Admitted work
retains cleanup ownership, and this release adds neither an active-operation timeout
nor a process-queue capacity limit. See [audit evidence](../../library/audit-evidence.md).

If a consumer must roll back, explicitly install the previously verified 2.0.0
artifact and stop using the new CLI output options. Preserve snapshot/recovery/audit
files; do not remove evidence or move registry tags as a rollback mechanism.
